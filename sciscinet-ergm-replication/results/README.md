# Archived outputs

This directory stores the supplied, publication-facing aggregate results. It intentionally excludes raw source data, author-level processed networks, saved model objects, and verbose workstation logs.

Run outputs should be written to `results/recomputed/`, which is excluded by `.gitignore`. Use `scripts/05_verify_archived_results.py` to compare recomputed coefficient tables against this archive.

See [docs/RESULTS_GUIDE.md](../docs/RESULTS_GUIDE.md) for a file-by-file description.
