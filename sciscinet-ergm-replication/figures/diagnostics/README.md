# M4 goodness-of-fit figures

`m4_gof/separate/` contains one supplied GOF PDF per journal-specific M4 model. Each PDF displays the model-statistic, geodesic-distance, degree, edgewise-shared-partner, and dyadwise-shared-partner comparisons produced by the archived diagnostic run.

The pooled block-diagonal diagnostic plot is intentionally absent: the supplied run log records a vector-memory failure before it completed.
