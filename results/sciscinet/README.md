# SciSciNet result tables

separate/ contains M0--M4 aggregate results across Cell, Ecological
Applications, Geology, Journal of the ACM, Nature Climate Change, Nature
Materials, Organization Science, Psychological Science, The Economic Journal,
and The New England Journal of Medicine. block/ contains the corresponding
block-diagonal M4 model summaries.

block_m5d_gwdegree/ contains the final pooled M5-D coefficients, settings,
constrained model-statistic GOF table, text export, and GOF figure. M5-D is
M4 plus gwdegree(0.50, fixed = TRUE) under one global density term and
blockdiag. It is the current pooled structural model for SciSciNet.
