# GHTorrent result tables

separate/ and block/ contain aggregate estimates for C, C++, CSS, HTML, Java,
JavaScript, Jupyter Notebook, Python, Ruby, and TypeScript.
block_m5d_gwdegree/ contains the final pooled M5-D coefficients, settings,
constrained model-statistic GOF table, text export, and GOF figure.

M5-D is M4 plus gwdegree(0.50, fixed = TRUE) under one global density term
and blockdiag. The older GHTorrent fixed-decay GWESP workflow is M5-E and is
retained as a supplementary sensitivity analysis, not as the pooled primary
model.
