# MyDreamTeam result tables

separate/ and block/ contain aggregate M4, fit, and network-summary tables
for the ten selected sessions. block_m5d_gwdegree/ contains the final pooled
M5-D coefficients, settings, constrained model-statistic GOF table, text
export, and GOF figure.

The current pooled structural model is M5-D, defined as M4 plus
gwdegree(0.50, fixed = TRUE), with one global density term and blockdiag.
Classroom-team input files and the preprocessing code that exposes restricted
records are not part of this public release.

The historical fixed-decay GWESP workflow is not the current primary model.
