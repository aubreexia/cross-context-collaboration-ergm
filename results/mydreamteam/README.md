# MyDreamTeam result tables

`separate/` and `block/` contain only aggregate M4, fit, and network-summary
tables for the ten selected sessions. Classroom-team input files and the
preprocessing code that exposes restricted records are not part of this public
release.

The fixed-decay GWESP M5 sensitivity fits did not yield usable converged
estimates for MyDreamTeam and are retained only as transparent failure records.
The dyad-independent M0--M4 models are the primary analyses.
