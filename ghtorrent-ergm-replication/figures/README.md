# Figures

The PNG files in `main_text/` were generated from the archived M4 coefficient tables with `scripts/04_make_main_figures.py`. They are 600 dpi and can be regenerated without access to author-level input data.

The ten supplied separate-model M4 GOF PDFs are in `diagnostics/m4_gof/separate/`. They are retained as supplementary diagnostic figures; the pooled block-diagonal GOF is not included because the supplied run failed from insufficient vector memory.

Do not edit the PNGs by hand. Change the figure script or source coefficient tables and regenerate them instead.
